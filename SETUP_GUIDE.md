# Complete Setup Guide - Clean Voice Studio\n\n## 📋 Overview\n\nClean Voice Studio consists of two repositories:\n\n1. **Frontend**: https://github.com/lamiusma40-png/clean-voice-studio\n2. **Backend**: https://github.com/lamiusma40-png/clean-voice-studio-backend\n\n---\n\n## 🚀 Getting Started\n\n### Prerequisites\n- Node.js 16+ (LTS recommended)\n- npm or yarn\n- Git\n- Code editor (VS Code recommended)\n\n### Step 1: Setup Frontend\n\n```bash\n# Clone frontend repository\ngit clone https://github.com/lamiusma40-png/clean-voice-studio.git\ncd clean-voice-studio\n\n# Install dependencies\nnpm install\n\n# Create environment file\ncp .env.example .env.local\n\n# Start development server\nnpm run dev\n```\n\n✓ Frontend will be available at: `http://localhost:5173`\n\n### Step 2: Setup Backend\n\n```bash\n# Clone backend repository (in another terminal)\ngit clone https://github.com/lamiusma40-png/clean-voice-studio-backend.git\ncd clean-voice-studio-backend\n\n# Install dependencies\nnpm install\n\n# Create environment file\ncp .env.example .env.local\n\n# Start backend server\nnpm run dev\n```\n\n✓ Backend API will be available at: `http://localhost:5000`\n\n---\n\n## ⚙️ Configuration\n\n### Frontend Configuration (`.env.local`)\n\n```env\nREACT_APP_API_URL=http://localhost:5000/api\nREACT_APP_API_KEY=your_api_key_here\nREACT_APP_MAX_FILE_SIZE=104857600\nREACT_APP_ENV=development\n```\n\n### Backend Configuration (`.env.local`)\n\n```env\nPORT=5000\nNODE_ENV=development\nCORS_ORIGIN=http://localhost:5173\nMAX_FILE_SIZE=524288000\nAUDIO_UPLOAD_DIR=./uploads/audio\nPROCESSED_AUDIO_DIR=./uploads/processed\nAPI_KEY=your_secret_api_key_here\n```\n\n---\n\n## 🔌 API Endpoints\n\n### Health & Status\n```\nGET /health                    # Server health check\nGET /api/version              # API version info\n```\n\n### Audio Enhancement\n```\nPOST /api/enhance             # Upload and enhance audio\nGET /api/enhance/status/:id   # Get enhancement status\n```\n\n### Voice Transformation\n```\nPOST /api/transform           # Transform voice\nGET /api/transform/status/:id # Get transformation status\nGET /api/transform/voices     # List available voices\n```\n\n### Projects Management\n```\nGET /api/projects             # List all projects\nPOST /api/projects            # Create new project\nGET /api/projects/:id         # Get project details\nPUT /api/projects/:id         # Update project\nDELETE /api/projects/:id      # Delete project\nGET /api/projects/:id/export  # Export project audio\n```\n\n---\n\n## 🧪 Testing\n\n### Test Frontend\n\n```bash\ncd clean-voice-studio\n\n# Type checking\nnpm run type-check\n\n# '@/services/audioProcessing'\n\nconst enhancedBlob = await enhanceAudio(audioBlob, mode, settings)\n// This makes a POST request to /api/enhance\n```\n\n### Service Layer\n\nAll API calls go through `src/services/`:\n\n```typescript\n// src/services/client.ts - Axios configuration\nexport const apiClient = axios.create({\n  baseURL: process.env.REACT_APP_API_URL,\n  headers: {\n    'x-api-key': process.env.REACT_APP_API_KEY\n  }\n})\n\n// src/services/audioProcessing.ts - Enhancement service\nexport const enhanceAudio = async (blob, mode, settings) => {\n  const formData = new FormData()\n  formData.append('audio', blob)\n  formData.append('mode', mode)\n  formData.append('intensity', settings.intensity)\n  \n  const response = await apiClient.post('/enhance', formData)\n  return response.data\n}\n```\n\n### State Management\n\nStore manages application state (Zustand):\n\n```typescript\n// src/store/useAudioStore.ts\nexport const useAudioStore = create((set) => ({\n  currentProject: null,\n  enhancedAudio: null,\n  \n  enhanceAudio: async (blob, mode, settings) => {\n    const result = await audioProcessing.enhanceAudio(blob, mode, settings)\n    set({ enhancedAudio: result })\n  }\n}))\n```\n\n---\n\n## 🚀 Deployment\n\n### Deploy Frontend\n\n**Vercel** (Recommended):\n```bash\nnpm i -g vercel\nvercel\n```\n\n**Netlify**:\n```bash\nnpm run Check backend is running: `curl http://localhost:5000/health`\n2. Verify API URL in `.env.local`\n3. Check CORS configuration in backend\n4. Check browser console for errors\n\n### Port Already in Use\n\n```bash\n# Find process using port 5000\nlsof -i :5000\n\n# Kill process\nkill -9 <PID>\n\n# Or use different port\nPORT=5001 npm run dev\n```\n\n### Module Not Found\n\n```bash\n# Clear node_modules and reinstall\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### TypeScript Errors\n\n```bash\n# Check for type errors\nnpm run type-check\n\n# Clear TypeScript cache\nrm -rf node_modules/.cache\n```\n\n---\n\n## 🤝 Contributing\n\n1.
